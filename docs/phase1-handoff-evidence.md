## 5. SQLite schema, index version, cache-location behaviour

`src/ingestion/index-schema.ts`. One `entry` table plus `meta`; six B-tree indexes
(`ref_class`, `property_category`, `value_num`, `path_folded`, `key`, `collection`) and an
FTS5 virtual table over path/description/scopes with `unicode61 remove_diacritics 2`
pinned explicitly.

`INDEX_VERSION = 1.0.0`. `meta` records source hash, source schema version, index version,
**SQLite library version**, FTS tokenizer, build time, entry count, source bytes.

Cache location is `derivedDir`, supplied through typed config with **no default** — absence
throws. Index files are `*.db` and git-ignored: committing one would create a second
authority.

## 9. Test-failure history and final status

Failures encountered and what each turned out to be. **Nine of eleven were defects in my
own tests or fixtures, not in the code under test** — worth recording, because a suite
that never fails during construction is a suite that is not checking anything.

| # | Failure | Cause | Resolution |
|---|---|---|---|
| 1 | `@types/node` missing | scaffold gap | added |
| 2 | ajv/ajv-formats CJS interop | ESM default-import of CJS | named import + normalising cast |
| 3 | `erasableSyntaxOnly` rejected a parameter property | strict config working | declared the field explicitly |
| 4 | Ajv `strictRequired` in conditional branches | `required` needs the property in scope | restated `properties` in each `then` |
| 5 | Ajv `strictTypes` on a union type | `allowUnionTypes: false` | explicit `oneOf`, rather than weakening every schema |
| 6 | Route module unreadable | missing `routes/` path prefix | fixed the path |
| 7 | Phrase assertion spanned a hard-wrapped line | **my test** | normalise whitespace before matching |
| 8 | `SA-16` "missing" from the register | **my regex**; it exists as SA-16a–d | `(?![0-9])` instead of `\b` |
| 9 | Fabricated-path guard flagged my own provenance note | **my fixture** | reworded; the allowlist must not be satisfiable by deleting the discussion |
| 10 | Every composition failed `IDENTITY_MISMATCH` | **my fixtures** used hand-written candidate ids | derive them as the index builder does |
| 11 | Key-order test passing for the wrong reason | **my test**: `JSON.stringify(v, keyArray)` *filters* | rebuild with reversed insertion order |

Two were genuine design finds: `state` is an overloaded field name (fixed with a
path-scoped exemption), and the prototype's recall contained two ties resolved by chance.

## 10. Corrected resolver ground truth

`tests/fixtures/active/resolver-ground-truth.json` — 12 cases, both v1 defects corrected:
resolution #6's fabricated border-width path → `stroke/thin` (value 1.0, key `75ab1461…`),

Each case carries `allowed_rank` **and a written basis**. Windows were assigned before the
